# ADVENT Powered Speaker

This is a self contained powered speaker that I acquired a pair of from my grandfather. 

I modified them slightly (as documented) to allow for the use of a standard grounded power cord.

Each speaker has 2 PCBs (Power and main) which are each in their own separate KiCAD project file.


NOTE: The schematics are not fully accurate, as I didn't include the random extra pads/holes included in the PCB that were unconnected.
